OBS Restream ポータブル版
==========================

OBS Studio（ポータブルモード）に、同梱の Restream ダッシュボードを最初から組み込んだ
配信用セットです。OBS 本体のインストールは不要で、システム側の OBS 設定
(%APPDATA%\obs-studio) には一切触れません。

■ 使い方
 1. zip を「ローカルドライブ」上の好きなフォルダに展開します
    （ネットワークドライブ・OneDrive の同期フォルダ直下などは避けてください）。
 2. Start-OBS-Restream.bat をダブルクリックします。
    初回はファイルのブロック解除のため少し時間がかかります。
    Windows の SmartScreen が出た場合は「詳細情報」→「実行」を選んでください。
 3. 黒いコンソール画面（最小化されます。閉じないでください）とともに OBS が起動し、
    右側に「Restream」ドックが表示されます
    （見当たらないときは OBS の メニュー「ドック」→「Restream」）。
 4. OBS の「設定」→「配信」で、配信先サービス/サーバーとストリームキーを貼り付けます。
 5. ドックの「OBS」タブにある「セットアップ」ボタンを 1 回押すと、
    動画スロット用のソース (VideoSlot0, VideoSlot1, ...) がシーン「Restream」に作られます。
    以降の配置は自動で同期されます。
 6. 「配信開始」を押します。

■ 仕組み（ローカルサーバー）
 ダッシュボード (app フォルダ) は、Start-OBS-Restream.bat の実行中だけ
 http://localhost:48610/ で配信されます。OBS のドックとブラウザソースはここを読み込みます。
 （Twitch の埋め込みプレーヤーは、親ページが localhost でないと表示を拒否するため、
 この方式にしています。）
 - 配信は自分のパソコン内 (localhost) 限定で、外部ネットワークには公開されません。
   そのため Windows ファイアウォールの確認ダイアログは出ません。
 - OBS を終了すると、サーバーもコンソール画面も自動で終了します。OBS が異常終了した
   場合も同様です。
 - OBS の使用中は、コンソール画面を閉じないでください。閉じるとサーバーが止まり、
   ドックとブラウザソースが空白になります（OBS を終了し、bat から起動し直せば復旧します）。
 - ポート番号は config\obs-restream.json の appPort に保存され、毎回同じ値が使われます
   （ダッシュボードの設定はポートごとに保存されるため、固定しています）。

WebSocket のパスワードは初回起動時に自動生成され、ダッシュボードへ自動で渡されます。
手動で入力する必要はありません。

■ フォルダの移動
 フォルダごと移動しても問題ありません（URL にフォルダの場所は含まれません）。
 旧版 (http://absolute/ 方式) の config を引き継いだ場合も、次回起動時に
 Start-OBS-Restream.bat がシーン内の URL を自動で更新します。
 必ず Start-OBS-Restream.bat から起動してください
 （bin\64bit\obs64.exe を直接開くと、配信サーバーが無いためドックが空白になります）。

■ 初期化（リセット）
 OBS を終了して、このフォルダの config フォルダを削除し、再度
 Start-OBS-Restream.bat を実行します。パスワード・シーン・プロファイル・
 ストリームキーなどすべて初期状態に戻ります。
 （Start-OBS-Restream.bat -Reset でも同じ操作ができます）

■ 更新
 - アプリ (app フォルダ) だけ更新: 新しい app フォルダで置き換えるだけです。
   config は保持されます。
 - OBS 本体の更新: 新しい配布 zip を別フォルダに展開し、古い config フォルダを
   新しいフォルダへコピーします。OBS の自動アップデートは無効化しています。

■ トラブルシュート
 - ドックが真っ白: OBS を終了し、Start-OBS-Restream.bat から起動し直してください
   （コンソール画面を閉じていないか確認）。
 - 「ポート 48610 は他のプログラムが使用中」と表示された: 別の Start-OBS-Restream.bat が
   動いていないか、他のアプリが同じポートを使っていないか確認してください。
   使用中のアプリを終了できない場合は、別のポートで起動します:
     Start-OBS-Restream.bat -AppPort 48611
   （指定したポートは保存され、次回以降も使われます。ポートが変わるとダッシュボードの
   保存済み設定は引き継がれないため、OBS 接続などを再設定してください。シーン内の
   ソースの URL は自動で張り替わります）
 - 「OBS 未接続」などの表示: ドックの「OBS」タブで URL が ws://127.0.0.1:4455 に
   なっているか確認してください。他のアプリがポート 4455 を使っていると接続できません
   (config\obs-restream.json の port を変更して再起動)。
 - 動作ログ: OBS の「ヘルプ」→「ログファイル」。
